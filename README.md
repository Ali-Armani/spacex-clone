# SpaceX Website Clone

A front-end clone of the official [SpaceX](https://www.spacex.com) website, built as a hands-on practice project to strengthen skills,
in responsive layout design, semantic HTML, modern CSS, and interactive JavaScript.


![Status](https://img.shields.io/badge/status-in%20progress-yellow)


![License](https://img.shields.io/badge/license-MIT-blue)



---

## 🚀 Overview

This project recreates the visual design and layout of the SpaceX website with a focus on:

- Pixel-accurate, responsive UI across desktop, tablet, and mobile
- Clean, semantic, and accessible HTML structure
- Modern CSS techniques (Flexbox, Grid, custom properties)
- Interactive elements and smooth UX behavior with JavaScript

DISCLAIMER:
The goal is **NOT** to replicate SpaceX's business, branding, or proprietary content for commercial use — it is a learning exercise intended to demonstrate front-end development skills for a portfolio.
